WHAT THIS IS
------------
A local research and PAPER-TRADING program for XAU/USD (gold), EUR/USD, GBP/USD.
It downloads free price data, analyses the market on every 5-minute candle, and
tells you two separate things:
  1) DIRECTIONAL FORECAST  - UP / DOWN / NEUTRAL for the next 6 candles
  2) TRADE DECISION        - BUY / SELL / WAIT (and CANNOT ASSESS if data is bad)
It NEVER places real orders. There is no broker order code in the project.

IMPORTANT HONEST RESULT
-----------------------
Tests on 12 months of real data with real spread, slippage and commission showed
that none of the 4 strategies and none of the trained models makes money after
costs (about -0.15 R per trade for gold, -0.29 R for EUR/USD and GBP/USD).
So the normal answer is WAIT with the blocker NO_VALIDATED_EDGE. That is the
program being honest, not broken. A 70-80% win rate is NOT achieved and is NOT
promised. Not financial advice.

 PART 1 - RUN IT LOCALLY (Windows PowerShell)
================================================================================

1.1  EVERY TIME you open a new PowerShell window
-------------------------------------------------
    cd F:\Trading_Bot
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
    .\.venv\Scripts\Activate.ps1
(The prompt must start with (.venv). If it does not, activate again.)

1.2  ONE-TIME SETUP (only if .venv does not exist)
--------------------------------------------------
    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    copy .env.example .env         (optional - works without any keys)

1.3  FIRST RUN
--------------
    python main.py doctor
        Health check. Shows PASS / WARN / FAIL for packages, database,
        providers, stored data, news calendar, models.
        WARN for "no model" and "calendar unavailable" is normal at first.

    python main.py sync --all --days 90
        Downloads 90 days of free bid/ask history for all 3 symbols.
        Takes several minutes and may look quiet - the free Dukascopy server
        throttles downloads and the program retries. Just wait.
        Failed days are retried automatically on the next sync.

    python main.py signal --symbol EURUSD --auto-sync
        Downloads anything missing, then prints the latest analysis.

1.4  START THE BROWSER DASHBOARD
--------------------------------
    python main.py dashboard
        Starts the server and opens http://127.0.0.1:8000 in your browser.
    python main.py serve
        Same, but does not open the browser.
    Keep the PowerShell window OPEN. Closing it stops the dashboard.
    Stop with Ctrl+C.
    API documentation page (auto-generated): http://127.0.0.1:8000/docs
    If port 8000 is busy:  python main.py serve --port 8001

1.5  ALL COMMANDS
-----------------
    python main.py doctor [--deep]
        --deep also tests the internet connection to each data provider.

    python main.py sync --all                 (all symbols)
    python main.py sync --symbol XAUUSD       (one symbol; comma list allowed)
        --days 365            go further back in history
        --provider yahoo      sync only one data source
        "fetch" is the same command.

    python main.py signal --symbol EURUSD [--auto-sync] [--json] [--no-persist]
    python main.py signal --all --auto-sync
        --auto-sync   download missing candles first, then analyse
        --json        print the raw JSON result instead of text
        --no-persist  do not save this analysis in the database

    python main.py backtest --all --walk-forward
        Replays all strategies on stored history with realistic costs.
        Takes 1-3 minutes per symbol.

    python main.py train --symbol XAUUSD      (or --all)
        Trains and tests machine-learning models. Never switches them on.

    python main.py model-status --all
    python main.py model-approve <version-name>    (you approve a CANDIDATE)
    python main.py model-rollback --symbol XAUUSD  (switch the model off)

    python main.py monitor --all --on-candle-close
        Analyses automatically after every 5-minute candle while the laptop
        is on. Add --once to run a single cycle. Ctrl+C to stop.

    python main.py paper        paper-trading summary
    python main.py calendar     refresh news calendar + upcoming events

    Exit codes: 0 = fine, 1 = error, 2 = data blocked (stale / missing).

1.6  DAILY ROUTINE
------------------
    1. Activate the venv (section 1.1)
    2. python main.py dashboard
    3. In the browser: click "Sync all (job)", then "Start monitor"
    4. Leave it running. Ctrl+C in PowerShell when done.
The program works ONLY while the laptop is on. After days offline, run a sync:
missed candles are re-downloaded. Ticks that happened between candles while the
laptop was off cannot be recovered.

1.7  DATA SOURCES (all free)
----------------------------
    History (default)  Dukascopy: real BID and ASK, about 1 day behind.
    Live (default)     Yahoo: EUR/USD and GBP/USD only, MID price only, the
                       spread is an ASSUMPTION (labelled "ASSUMED").
    Gold (XAU/USD)     No free live source -> shows FEED_STALE. For live gold
                       create a free OANDA practice account and put in .env:
                           OANDA_TOKEN=your_practice_token
                           OANDA_ACCOUNT_ID=your_account_id
                           FOREX_PROVIDER=oanda
                       then run: python main.py doctor --deep
                       (OANDA code is written from the docs but NOT yet tested
                       against a real account.)
    News calendar      Free Forex Factory weekly feed (unofficial).

2.7  PAGE 5 - BACKTEST ANALYTICS
--------------------------------
    "Run backtest + walk-forward (job)"  runs in background, 1-3 minutes
    Tiles: trades, win rate, net expectancy (average profit per trade in R;
           1 R = the amount risked), profit factor (above 1 = profitable),
           max drawdown
    Equity curve (cumulative R)
    Strategies table (with 95% range of win rate)
    Walk-forward table: model re-trained on the past, tested on the next unseen
           period - the closest thing to a live test
    Breakdowns: by session, regime, month, side (long/short)
READ "Net EV (R)", NOT win rate. Negative = loses money after costs.

3.1  THE TEXT ANSWER (python main.py signal ...)
------------------------------------------------
Example:
    EUR/USD  as of 2026-10-27T16:00:00+00:00 | feed HEALTHY data=LIVE provider=dukascopy+yahoo
    data: last bar 2026-10-27T15:55:00+00:00, age 2.6 min, bars 73871, recent gaps 0
    regime: TREND_DOWN (NORMAL vol)  session: LONDON_NY_OVERLAP  price: bid 1.11465 / ask 1.11475 (spread 0.0001, ASSUMED)
    DIRECTIONAL FORECAST: DOWN over next 6 M5 bars  P(up)=n/a [NOT_CALIBRATED]
    TRADE DECISION: WAIT  (NO_TRADE, strength NONE)
      blockers: NO_SETUP
      warnings: SPREAD_ASSUMED_NOT_LIVE, SOURCE_SEAM_PRICE_JUMP
Meaning line by line:
    as of          the time of the decision (close of the last 5-minute candle)
    feed / data    HEALTHY+LIVE = fresh data; STALE = too old
    provider       where the prices came from (history + live source)
    last bar / age how old the newest closed candle is
    bars / gaps    stored candles; missing candles in the last 200
    regime/session market state and trading session
    price          bid/ask; ASSUMED = spread is an estimate
    FORECAST       direction lean; P(up) only when a calibrated model is active
    TRADE DECISION BUY/SELL/WAIT; blockers = exact reasons for WAIT
When a trade IS allowed you also get: strategy, entry zone, SL, TP1/TP2/TP3,
R:R, expected move %, probability (+ status), expected value (R), holding time
estimate, valid-until time.

3.2  THE JSON ANSWER (python main.py signal --symbol X --json, or the API)

3.5  HOW TO TELL WHETHER THE RESULT IS CORRECT
----------------------------------------------
    1. Compare bid/ask on the Command Center with a live chart (EUR/USD and
       GBP/USD should be within a pip or two). Feed age should be under ~10 min.
    2. Every card must show BOTH a forecast and a decision. WAIT with a clear
       blocker is a valid result.
    3. Backtest Analytics shows the truth about profit. Today all strategies
       have negative net EV.
    4. Leave "Start monitor" on for weeks and read the Paper Journal. That is
       the real forward test.
    5. Run the automated tests:   python -m pytest tests -q   (about 5 minutes,
       no internet needed; 75 tests).

3.6  HOW A DECISION IS MADE (short)
-----------------------------------
    data check -> market regime -> 4 strategies run independently
    (trend continuation, breakout+retest, liquidity sweep reversal, range
    mean reversion) -> each candidate needs PROVEN positive profit after costs
    (from the backtest, or from an approved calibrated model) -> safety gates
    (stale data, spread, news, daily loss limit, open positions) -> result.
    A single indicator disagreeing (RSI, MACD, etc.) never blocks a trade.
    Only data problems, costs, news, risk limits and "no proven edge" can.

3.7  RISK SETTINGS (change in .env or forexintel\config.py, then restart)
------------------------------------------------------------------------
    Risk per paper trade 0.5% of 10,000 simulated equity
    Daily loss limit 2%; one position per symbol; max 2 same-direction USD trades
    Spread limit 25% of ATR; news blackout 30 min before / 15 min after
    Targets: TP1 = 1.0R, TP2 = 1.8R, TP3 = 2.8R; trades time out after 12 candles

 PART 4 - TROUBLESHOOTING
================================================================================
    "signal --auto-sync" looks stuck
        The Dukascopy server is throttling. Wait 3-5 minutes, or press Ctrl+C
        and run:  python main.py signal --symbol EURUSD   (no --auto-sync).
        Live prices only:  python main.py sync --symbol EURUSD --provider yahoo
    Gold shows FEED_STALE
        Expected without a live source. Add an OANDA practice token (1.7).
    CANNOT ASSESS / INSUFFICIENT DATA
        python main.py sync --all --days 90
    "running scripts is disabled" when activating the venv
        Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
    "python is not recognized"
        Activate the venv first (section 1.1).
    Port 8000 already in use
        python main.py serve --port 8001   then open http://127.0.0.1:8001
    Dashboard asks for a token
        You set API_TOKEN. Click "Token" and enter it.
    Chart does not appear
        Needs internet for the chart script; everything else works offline.
    Anything else
        python main.py doctor, then Settings / Health and the job logs.
